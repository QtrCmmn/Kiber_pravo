# Руководство по добавлению сценариев

## Формат сценария

Каждый сценарий — объект в массиве `SCENARIOS` в `js/scenarios.js`.

```js
{
  id: 'unique-id',           // латиница, kebab-case, уникальный
  title: 'Название',         // короткое, понятное школьнику
  tagline: '«Цитата мошенника»', // что говорит мошенник в первой фразе
  icon: '<svg>…</svg>',      // иконка 24×24, material symbol
  attacker: { name: 'Кто звонит', status: 'статус в шапке' },
  intro: 'Описание ситуации',  // 1-2 предложения
  timeLimit: 30,             // секунд на ответ
  start: 's1',               // id первого шага
  steps: { /*…*/ }
}
```

## Структура шага

```js
s1: {
  messages: [
    { text: 'Текст от мошенника', delay: 650 }  // 600-800ms
  ],
  question: 'Вопрос пользователю?',
  options: [
    {
      text: 'Текст варианта ответа',
      safe: true,              // true = правильный, false = опасный
      feedback: 'Объяснение почему это верно/неверно',
      next: 's2'               // id следующего шага, 'win' или 'lose'
    }
  ],
  onTimeout                    // константа onTimeout из scenarios.js
}
```

## Правила

### Количество опций
- На каждом шаге **3-4 варианта** ответа
- Ровно **1 safe** (правильный), остальные unsafe
- Исключение: первый шаг и последний шаг могут иметь 2 опции

### Запрет `next: 'lose'`
- **Ни один option не должен иметь `next: 'lose'`**
- Все unsafe-опции ведут на следующий шаг (жизнь снимает движок)
- Проигрыш наступает только когда `lives === 0` (после 3 ошибок)

### Мини-ветки
- **1-2 мини-ветки** на сценарий (s1b, s4b и т.д.)
- Мини-ветка — 1 шаг с 2 опциями, который ведёт обратно в основной поток
- Создаётся когда выбор на шаге принципиально меняет ход разговора

### Ранняя победа
- **1-2 точки** досрочной победы на сценарий
- Safe option с `next: 'win'`
- Мотивирует решительные правильные действия (блокировка карты, звонок в 102)

### onTimeout
- Только `feedback: 'текст'`, без поля `next`
- Движок сам снимает жизнь и переходит по safe-ветке

### Шаги
- **6-10 шагов** (включая мини-ветки, исключая победу/проигрыш)
- 1-2 сообщения мошенника на шаг
- Каждое сообщение — 1-2 предложения максимум

## Стиль текстов

- Аудитория: **школьники 10–17 лет**
- Без канцелярита, сложных юридических терминов
- Мошенник говорит **убедительно, с давлением, иногда агрессивно**
- Safe feedback: объясняет **почему** это безопасно
- Unsafe feedback: объясняет **чем именно** опасен этот выбор
- Длина feedback: 1-2 предложения

## Чеклист

- [ ] id уникален, kebab-case
- [ ] 3-4 опции на каждом шаге
- [ ] Ни один option не ведёт в `'lose'`
- [ ] Все пути ведут в `'win'` (в конце или досрочно)
- [ ] 1-2 мини-ветки
- [ ] 1-2 ранние победы
- [ ] onTimeout без `next`
- [ ] 6-10 шагов
- [ ] Язык живой, для школьников
- [ ] Mermaid-граф в `assets/docs/scenarios/<id>.md`
